Stack Frame Mechanics -> CPU Registers + Instructions + Memory Addressing

```
Instructions -> mov, lea, jmp, push, pop, syscall ... 
CPU Registers -> EAX, RAX, RSP, RCX, R8, R9 ...
Memory Addressing -> [rbp-8], [rax+rcx*4+0x10], [rip+0x2000] (RIP-relative)
```
